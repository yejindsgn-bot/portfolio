Problem

같은 기능 설명이 5개 탭에 반복되고, 기능 탐색과 구매가 분리돼 있었습니다. 사용성 테스트에서 83%가 예상 경로를 벗어났습니다.

What I did

AI로 만든 초안을 리서치 근거로 검수하고, 반복되는 버튼 · 카드를 Component Property와 Variant로 정리했습니다. Selected 상태는 컴포넌트가 달라도 같은 색상 규칙을 쓰도록 정했습니다.

Result

디자이너 3명이 같은 컴포넌트 세트로 화면을 제작했고, 구매까지 최대 10단계였던 경로를 하나의 흐름으로 제안했습니다.

STEP 01Problem문제 정의

같은 기능 설명이 탭마다 다른 형태로 반복되고,
사용자는 상품 탭에서 길을 잃었습니다

운영하던 SmartThings 페이지는 삼성닷컴 평균 대비 이탈률이 높고 체류시간이 짧았습니다. 5개 탭에 비슷한 형식의 콘텐츠가 반복돼, 사용자는 같은 정보를 여러 번 확인해야 했고 기능 탐색과 구매는 서로 다른 페이지로 나뉘어 있었습니다.

이유를 확인하려고 Maze로 비대면 사용성 테스트를 진행했습니다. 체험에서 구매까지 하나로 잇는 경험과, 그 경험을 일관되게 만들 컴포넌트 규칙이 필요했습니다.

02

Samsung ACE

2025.03 - 2025.06UX/UI Designer · 디자이너 3인
TokensComponentsXD Shared LibraryPC / MO RulesPublisher QA

Problem

신규 서비스라 상품(PD) 카드, 마이페이지, 성과 그래프처럼 기존 운영 사이트에 없는 UI가 필요했습니다.

What I did

사용자 상태별 흐름에서 반복되는 UI를 뽑아 토큰 · 컴포넌트를 XD 공유 라이브러리로 정의하고, 시안 단계부터 기획 · 퍼블리셔와 같은 기준으로 작업했습니다.

Result

기획 변경은 컴포넌트 기준으로 점검하고, QA에서 브레이크포인트별 오류를 잡아 런칭했습니다. 런칭 후 3개월간 약 2.2만 회 방문을 기록했습니다.

STEP 01Problem문제 정의

기존 운영 사이트의 컴포넌트로는
새 서비스를 만들 수 없었습니다

Samsung ACE는 삼성전자 사업자가 외부 채널에서 제품을 홍보하고 판매 성과로 수익을 얻는 신규 제휴 마케팅 서비스입니다. 상품(PD) 카드, 마이페이지, 성과 그래프처럼 기존 삼성닷컴에 없던 UI가 필요했습니다.

디자이너 3명과 기획 · 퍼블리셔가 시안 단계부터 같은 기준으로 움직이지 않으면, 화면마다 규칙이 갈라지고 QA 비용이 커지는 구조였습니다. 사용자는 로그인 전 · 후 상태에 따라 필요한 정보가 달랐습니다.

STEP 02Process도출 과정

사용자 상태별 흐름을 먼저 정하고,
그 흐름에서 반복되는 UI를 뽑았습니다

로그인 전 메인은 서비스 이해와 가입, 로그인 후 메인은 제품 선택 → 링크 생성 → 공유 → 성과 확인으로 역할을 나눴습니다. 이 흐름에서 반복되는 요소를 추려 기존 삼성닷컴 기준과 맞출 것, 새로 정의할 것을 구분했습니다.

STEP 03Design설계안

기존 운영 사이트에 없던 UI를

Problem

외국인 관광객은 일부 지역에 몰리고, 새로운 지역을 찾는 여행자는 가입 · 결제 · 길찾기 같은 디지털 진입 단계에서 막혔습니다.

What I did

앱보다 먼저 손에 닿는 키링을 서비스의 시작점으로 정하고, 소리 알림 · 버튼 · 마이크와 스피커는 키링이, 비교와 선택은 휴대폰 화면이 맡도록 역할을 나눴습니다.

Result

발견부터 이동, 현장 경험, 다음 탐색까지 이어지는 경험으로 iF Design Award 2026 Concept Design을 수상했습니다.
