01

SmartThings Studio

2025.07 - 2025.12UX/UI Designer · 디자이너 3인
AI ResearchAI WireframeHuman ReviewUI Components

Problem

스마트홈 콘텐츠는 많았지만 구매로 이어지지 않았습니다. 사용성 테스트에서 83%가 예상 경로를 벗어났습니다.

What I did

Maze AI로 리서치를 분석하고, Uizard로 만든 화면 초안을 리서치 근거로 검수해 다시 설계했습니다. 핵심 컴포넌트와 추천 규칙을 정의했습니다.

Result

구매까지 최대 10단계·페이지 이동 7회였던 경로를 체험 → 추천 → 구매의 한 흐름으로 제안했습니다.

판단은 리서치 근거로 했습니다

  2. 02

  • KEEP3D 룸 뷰를 첫 화면의 중심으로공간 안에서 기기를 보여주는 구조는 체험 서비스의 핵심이라 유지했습니다.
  • CHANGE상품 그리드 → 생활 기능 카드리서치에서 상품 탭을 떠난 사용자가 83%였기에, 상품 나열 대신 라이프스타일에 맞는 기능을 먼저 보여주도록 바꿨습니다.
  • CHANGE번들 가격 요약 → 추천 단계로 분리체험 화면에서는 구매 정보를 덜어내고, 공간별 추천 목록에서 수량과 가격을 조정하도록 나눴습니다.
  • ADD3가지 질문 온보딩과 필터초안에는 개인화가 없었습니다. 함께 사는 사람·관심 경험·공간을 묻고, 답에 맞춰 룸 뷰를 다시 구성했습니다.
  • CHANGE범용 다크 UI → 삼성닷컴 톤흰 배경, 블랙 CTA, SamsungOne 서체 등 삼성닷컴 화면 기준으로 정리했습니다.

UI COMPONENTS & RULES

체험 흐름을 이루는 컴포넌트와
추천 규칙을 정의했습니다

온보딩, 룸 뷰, 추천 단계에서 반복해 쓰이는 요소를 컴포넌트로 묶고, 상태와 사용 규칙을 함께 정리했습니다.

Selection Chip

온보딩 질문의 답을 고르는 칩입니다.

  • Default 회색 라인
  • Selected 블루 라인 + 연한 블루 배경
  • Dimmed 단일 선택 질문에서 선택 후 나머지 비활성
  • Icon chip 경험 질문(Q2)은 아이콘 + 라벨, 복수 선택

Feature Card

룸 뷰 하단의 생활 기능 카드입니다.

  • Selected 블루 라인, 선택하면 룸 뷰가 해당 기기 장면으로 전환
  • 아이콘 + 기능명 2줄 이내
  • 가로 스크롤, 하단 고정 CTA와 함께 사용

Lifestyle Filter

온보딩 답변을 다시 바꾸는 필터입니다.

  • 질문별 아코디언 + 체크박스
  • 적용하기를 누르면 룸 뷰와 기능 카드를 다시 구성

Product Row & Space Accordion

추천 결과를 공간별로 묶어 보여줍니다.

  • 기능 라벨 → 제품 → 할인율·가격 → 수량 스테퍼
  • 더 알아보기는 해당 제품군 목록으로 이동
  • 공간 단위 아코디언, 하단에 장바구니·구매 CTA

Recommendation Rules

온보딩 답변을 추천 결과로 바꾸는 규칙입니다.

  • Q2 관심 경험 → 제품 후보 목록 결정
  • Q1 함께 사는 사람 → 제품별 대표 기능 선정
  • Q3 공간 → 공간에 맞는 제품만 선별
  • 공간별 중복을 줄여 룸 뷰에 제품 3개 배치
02

AI Generation Rules

2025.11 - 2026.09AI Art Director · 디자이너 3인
Generation RulesCommon / Negative PromptQuality CheckGlobal Guide

Problem

같은 캐릭터도 생성할 때마다 얼굴·비율·질감·의상이 달라져, 지사마다 결과물 품질이 흔들렸습니다.

What I did

캐릭터를 이루는 요소를 생성 규칙으로 정의하고, 반복된 오류를 Common·Negative Prompt로 구조화해 공통 에셋으로 등록했습니다.

Result

완성한 AI 캐릭터 가이드라인을 64개국 지사에 배포해, 제작 환경이 달라도 같은 품질을 유지하도록 했습니다.

Problem

신규 제휴 마케팅 서비스라 PD 카드, 마이페이지, 성과 그래프 등 기존 운영 사이트에 없는 UI가 필요했습니다.

What I did

Result

서비스를 런칭했고, 런칭 후 3개월간 약 2.2만 회 방문을 기록했습니다.
