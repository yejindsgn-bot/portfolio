01

Samsung ACE

2025.03 - 2025.06UX/UI Designer · 디자이너 3인
State-based MainEngagement LoopRecommendationDashboardLaunch

Problem

처음 온 사용자와 이미 활동 중인 회원은 메인에서 해야 할 일이 달랐습니다. 하나의 메인으로는 가입과 반복 홍보 활동을 함께 이끌기 어려웠습니다.

What I did

로그인 전 메인은 서비스 이해와 가입에, 로그인 후 메인은 활동 기반 추천 → 링크 생성 → 성과 확인으로 이어지는 반복 활동에 집중하도록 나눠 설계했습니다. 신규 UI는 컴포넌트로 정의해 퍼블리셔와 QA까지 진행했습니다.

Result

서비스를 런칭했고, 런칭 후 3개월간 약 2.2만 회 방문, ACE Gate 트래픽 비중 3.63%를 기록했습니다.

UX STRATEGY

이해부터 성과 확인까지
자연스럽게 이어지는 흐름을 설계했습니다

From Understanding To Action, In One Connected Flow.

ACE는 사용자의 상태에 따라 필요한 정보와 다음 행동이 달라지는 서비스입니다. 그래서 로그인 전에는 서비스 이해와 가입을, 로그인 후에는 제품 탐색 · 링크 생성 · 성과 확인을 빠르게 시작할 수 있도록 각 단계의 역할을 분명하게 나누고 자연스럽게 연결했습니다.

TAG SEOUL

2025.07 - 2026.02UX/UI Designer · 디자이너 3인
HyperlocalAI ChatNotificationGamificationiF Design Award 2026

Problem

외국인 관광객은 일부 지역에 몰리고, 새로운 지역을 가려는 여행자는 가입·결제·길찾기 같은 디지털 진입 단계에서 막혔습니다. 방한 여행 불편의 27.8%가 디지털 영역이었습니다.

What I did

NFC 태그 한 번으로 AI 채팅 추천 → 이동 · 결제 · 통역 → 지역 해금으로 이어지는 흐름을 설계했습니다. 새 지역에 도착하면 알림을 보내고, 지도 해금과 주변 쿠폰으로 다음 탐색을 이어가도록 했습니다.

Result

발견부터 이동, 현장 경험, 다음 탐색까지 하나의 순환 흐름으로 제안해 iF Design Award 2026 Concept Design을 수상했습니다.

03

SmartThings Studio

2025.07 - 2025.10UX/UI Designer · 디자이너 3인
PersonalizationRecommendation LogicUser FlowData × IntuitionAI Workflow

Problem

스마트홈 콘텐츠는 많았지만 구매로 이어지지 않았습니다. 사용성 테스트에서 83%가 예상 경로를 벗어났습니다.

What I did

운영 데이터와 비대면 사용성 테스트로 이탈 지점을 찾고, 3문항 온보딩과 추천 로직으로 사용자마다 다른 3D 룸 뷰 체험을 설계했습니다. AI로 만든 초안은 리서치 근거로 검수해 유지 · 변경할 것을 판단했습니다.

Result

구매까지 최대 10단계 · 페이지 이동 7회였던 경로를 체험 → 추천 → 구매의 한 흐름으로 제안했습니다.
